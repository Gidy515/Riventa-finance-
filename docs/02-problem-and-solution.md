# 2. Problem and Solution

## Problem hypothesis
Cross-border transactions coordinate parties, agreements, invoices, packing lists, certificates, inspections and payment obligations across organizations. Fragmented records can make it harder to spot inconsistent documents, establish evidence provenance and coordinate payment against agreed milestones. These are hypotheses; no market size, customer traction or measured impact is claimed.

## Solution
Riventa combines (1) a structured trade agreement, (2) private encrypted document exchange, (3) deterministic field extraction and cross-document checks with optional local-model explanations, (4) an attributable inspector attestation and (5) NEAR-enforced escrow settlement. It creates a coherent workflow, not a guarantee against fraud or default.

## Why hybrid
The NEAR contract owns authorization, state transitions and escrow liabilities. Private file bytes and detailed reports stay off-chain. Backend services handle encryption, parsing, analysis and indexing. Frontend presentation is not a security boundary.

## Trust assumptions
Users rely on wallet keys for account control, contract code for encoded rules, the token contract for token behavior, storage controls for confidentiality/availability, inspectors for physical observations and human reviewers for documentary decisions. Each trust dependency is disclosed.
