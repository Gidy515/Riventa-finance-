# ADR-005: Deadlines, Resolver Replacement and Admin Scope

- Status: Accepted
- Date: 2026-11-01

## Decision
Acceptance 7 days; funding 48 hours; buyer decision 72 hours; resolver decision 5 days. No automatic financial transition. Resolver replacement after timeout requires buyer and supplier approval in separate calls. Admin is 2-of-3 multisig; can manage inspector registry and pause new creation/funding only. No admin access to trade funds or dispute outcomes.
