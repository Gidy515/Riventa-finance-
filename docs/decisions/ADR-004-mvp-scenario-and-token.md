# ADR-004: Demo Scenario and Test Asset

- Status: Accepted
- Date: 2026-11-01

## Decision
Use a fictional 1,000 kg bagged cocoa-bean trade from Tema, Ghana to Lagos, Nigeria. Deploy a project-owned NEP-141 test token named Sandbox Dollar (SDD), 6 decimals, with no monetary value, redemption or stablecoin representation. All settlement tests use SDD on NEAR testnet.
